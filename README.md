> AI-powered adaptive learning companion for rural students: Bayesian Knowledge Tracing, open-source LLM quiz generation,
> Hindi/English support and an explainable dropout-risk dashboard for teachers.

**Live demo:** https://your-app.streamlit.app

EduAdapt gives rural students a personal AI tutor. It finds what each student does not yet understand,
serves practice questions at the right difficulty in English or Hindi, and shows teachers which students are
at risk of falling behind, with the reasons. The whole stack is free and open source.

## What it does

| Feature | AI/ML technique | File |
|---|---|---|
| Learning-gap detection (topic mastery after every answer) | Bayesian Knowledge Tracing (BKT), written from scratch with NumPy; parameters fitted by maximum likelihood | `modules/bkt.py` |
| Next-topic recommendation | Prerequisite-aware ranking on BKT mastery; content-based similarity (TF-IDF) | `modules/recommender.py` |
| Adaptive quizzes | Difficulty chosen from mastery; questions from a curated bank or generated by an open-weights **IBM Granite** LLM and validated | `modules/quiz_generator.py` |
| Hindi and English interface | Bilingual content; optional Hugging Face translation model | `modules/language.py`, `modules/content.py` |
| Voice | Text-to-speech (gTTS) and speech-to-text (Whisper), both optional | `modules/language.py` |
| Doubt answering | TF-IDF retrieval of the right lesson (+ optional LLM explanation) | `modules/quiz_generator.py` |
| Dropout / at-risk prediction | XGBoost classifier with SHAP explanations | `modules/dropout_model.py` |
| Teacher dashboard | Class mastery heatmap, risk table, per-student reasons | `pages/1_Teacher_Dashboard.py` |

## Setup and run

```bash
# 1. Get the code and enter the folder
cd eduadapt

# 2. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate

# 3. Install the core modules
pip install -r requirements.txt

# 4. Train the ML models (about 30 seconds; creates models/ and reports/)
python train_models.py

# 5. Run the tests (optional but recommended)
python -m pytest -q tests

# 6. Start the app
streamlit run app.py
```

Open http://localhost:8501, choose a language, type a name in the sidebar and take the diagnostic quiz.
Open **Teacher dashboard** from the sidebar and click **Load demo class** to see the dashboard with 30 simulated students.

If you skip step 4, the app trains quick models automatically the first time it starts.

## Optional: turn on the free AI features

Copy `.env.example` to `.env` and change the values you want. Install the extras first:

```bash
pip install -r requirements-optional.txt
```

**1. LLM quiz generation with IBM Granite (Hugging Face).** Needs about 6 GB of free RAM and a first-time model download.

```
EDUADAPT_LLM=hf
EDUADAPT_HF_MODEL=ibm-granite/granite-3.3-2b-instruct
```

**Or with Ollama** (install from ollama.com, then pull a Granite model; check the exact tag with `ollama list` or on the Ollama site):

```bash
ollama pull granite3.3:2b
```
```
EDUADAPT_LLM=ollama
EDUADAPT_OLLAMA_MODEL=granite3.3:2b
```

Generated questions are validated (4 distinct options, answer must be one of them). Invalid output silently falls back to the question bank.

**2. Hindi translation of generated text:** `EDUADAPT_TRANSLATE=hf`. The curated question bank is already bilingual and needs no model.

**3. Voice input:** install `ffmpeg`, then set `EDUADAPT_STT=whisper` (and optionally `EDUADAPT_WHISPER_MODEL=small` for better Hindi). Text-to-speech uses gTTS and needs an internet connection; disable with `EDUADAPT_TTS=none`.

## Use real datasets (recommended for your final report)

By default the models train on a **synthetic student simulator** so the project runs anywhere. For real results:

**Knowledge tracing with ASSISTments.** Download the 2009 skill-builder CSV from the ASSISTments data page (or Kaggle), then:

```bash
python train_models.py --assistments data/skill_builder_data.csv
```

It fits BKT per skill, reports held-out AUC, and uses the average parameters as defaults for the app's topics.

**Dropout model with your own or public data (UCI Student Performance, OULAD, a classroom pilot).** Build a CSV with these columns and run:

```
accuracy, attempts, active_days, mean_mastery, weak_topics, recent_accuracy, trend, days_since_last, at_risk
```
```bash
python train_models.py --dropout-csv data/my_students.csv
```

For OULAD, map total clicks to `attempts`, number of active days to `active_days`, average assessment score to `accuracy`, and withdrawn/failed to `at_risk = 1`.

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError` | Activate the virtual environment and run `pip install -r requirements.txt` |
| Model download is slow or runs out of memory | Keep `EDUADAPT_LLM=none` (question bank) or use a smaller model or Ollama |
| No audio | gTTS needs internet; check `EDUADAPT_TTS` |
| Whisper errors | Install `ffmpeg` and `openai-whisper` |
| Want a clean start | Delete `eduadapt.db`, and `models/` to retrain |

## Limitations and responsible use

- The question bank covers six Class 8 maths topics. Add rows to `modules/content.py` for more.
- Synthetic training data is a stand-in. Validate with real data before drawing conclusions.
- Students are minors: collect only a name or nickname, avoid personal data, and get school consent for any pilot.
- The risk score supports teachers; it should never be the only basis for a decision about a student.
